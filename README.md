# বাজার দর / BazarDor

A modern Bangla marketplace price tracker built to help users quickly check daily market prices for essential goods such as rice, lentils, oil, vegetables, fish, meat, and spices.

## Short Description

BazarDor is a lightweight e-commerce and price-tracking web app designed for shoppers who want a simple way to compare today’s market price with yesterday’s price and identify whether products are becoming more expensive or cheaper. The interface is clean, mobile-friendly, and tailored for Bangladesh market data.

## Technologies Used

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS
- DaisyUI
- MongoDB
- Better Auth
- Lucide React
- React Hot Toast

## Key Features

1. Daily market price overview
   - Shows the current prices of essential commodities in one dashboard view.

2. Price trend tracking
   - Highlights products whose prices have increased or decreased using clear up/down indicators.

3. Comparison with previous day
   - Lets users compare today’s price against yesterday’s price to understand market fluctuations.

4. Product detail browsing
   - Each product can be clicked to view more detailed information and pricing context.

5. Responsive and user-friendly design
   - Built with a clean, mobile-first layout for accessibility and smooth browsing on desktop and mobile devices.

## Getting Started

### Prerequisites

- Node.js 18 or later
- npm or yarn

### Installation

```bash
npm install
```

### Run the app locally

```bash
npm run dev
```

Then open:

```bash
http://localhost:3000
```

## Purpose

BazarDor aims to make everyday market monitoring easier for users in Bangladesh by turning complex pricing information into a simple, readable, and actionable shopping experience.
